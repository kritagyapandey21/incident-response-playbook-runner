# TR-008: Insider Data Theft by Departing Employees

**Base severity:** 3 (High)
**IOCs:** none (behavioural)

## Summary
Employees who have resigned or been given notice sometimes copy sensitive records
(salary data, customer lists, source code) to removable USB media or personal cloud
storage. DLP alerts show bulk copy events shortly after resignation.

## Behaviours
Bulk copy to removable media, unregistered USB device, mass file copy, data loss
prevention alert, departing employee, insider threat, resignation notice.

## Recommended Containment
1. [preserve] snapshot_host | host | Create a forensic image of {target} preserving chain of custody
2. [contain] disable_account | user | Suspend account {target} pending investigation
3. [contain] block_usb | host | Block removable storage on {target} via device control policy
4. [recover] notify_hr_legal | user | Open HR and legal case for {target}
