# TR-001: CryptVault Ransomware Campaign

**Base severity:** 4 (Critical)
**IOCs:** .cvault, README_RESTORE.txt, vlt.exe, 9f2c4e8a1b7d3f60c5e2a9b8d7f6e5c4b3a29180f7e6d5c4b3a2918070f6e5d4

## Summary
CryptVault is a human-operated ransomware family that targets Windows file servers and
backup infrastructure. Operators gain access with stolen service-account credentials,
stage the encryptor (commonly vlt.exe) in ProgramData, delete volume shadow copies with
vssadmin and then perform mass file encryption, renaming files with the .cvault extension
and dropping a ransom note named README_RESTORE.txt.

## Behaviours
Mass file encryption and rename activity, ransom note creation, shadow copy deletion,
encryptor binary executed from ProgramData, abuse of backup service accounts, rapid
file modification on network shares, ransomware extortion.

## Recommended Containment
1. [preserve] snapshot_host | host | Capture memory image and disk snapshot of {target} before any change, for forensics and decryptor research
2. [contain] isolate_host | host | Network-isolate {target} with EDR to stop encryption spreading to shares
3. [contain] disable_account | user | Disable compromised account {target} used to stage the encryptor
4. [contain] block_hash | hash | Block encryptor hash {target} fleet-wide in EDR
5. [eradicate] wipe_and_reimage | host | Wipe and reimage {target} from a known-good golden image | min_severity=High
6. [recover] restore_from_backup | host | Restore {target} data from the last clean offline backup
