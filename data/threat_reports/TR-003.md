# TR-003: Password Spraying Against Remote Access Gateways

**Base severity:** 2 (Medium)
**IOCs:** 45.155.205.99

## Summary
Botnet infrastructure is performing password spraying against internet-facing VPN and SSH
gateways: a small number of common passwords is tried across hundreds of distinct
usernames to avoid lockout. Most attempts fail; risk rises sharply if any authentication
succeeds or if MFA is not enforced.

## Behaviours
Many failed login attempts, many distinct usernames from one source IP, brute force,
password spraying, authentication failures on VPN gateway, credential stuffing.

## Recommended Containment
1. [contain] block_ip | ip | Block source address {target} at the perimeter
2. [contain] enforce_mfa_review | host | Verify MFA is enforced on all accounts authenticating to {target}
3. [recover] enable_enhanced_monitoring | host | Enable heightened authentication monitoring on {target} for 7 days
