# TR-012: SQL Injection Attempts Against Web Applications

**Base severity:** 2 (Medium)
**IOCs:** UNION SELECT, sqlmap

## Summary
Automated tools such as sqlmap send SQL injection payloads (UNION SELECT, boolean and
time-based blind) to web application parameters. Most are blocked by WAF rules.

## Behaviours
SQL injection, UNION SELECT payload, WAF block, sqlmap user agent, database error messages.

## Recommended Containment
1. [contain] block_ip | ip | Block {target} at WAF
2. [recover] review_waf_rules | host | Review WAF rules protecting {target}
