# TR-005: Web Shell Deployment via File-Upload Exploitation

**Base severity:** 3 (High)
**IOCs:** 91.240.118.172, img_cache.php

## Summary
Attackers exploit unrestricted file-upload endpoints on public web applications to plant
PHP web shells (frequently disguised as image cache files in uploads directories). The
web shell is executed through the web server process (apache2 / nginx / w3wp) and used
to run reconnaissance commands such as whoami and cat /etc/passwd, then to pivot to
back-end databases.

## Behaviours
Web shell file in uploads directory, PHP script spawning shell commands, web server
process spawning whoami, exploitation of upload endpoint, public web server compromise.

## Recommended Containment
1. [preserve] snapshot_host | host | Snapshot {target} disk and capture web server logs for forensics
2. [contain] block_ip | ip | Block attacker address {target} at WAF and perimeter firewall
3. [contain] quarantine_file | file | Quarantine web shell file {target}
4. [eradicate] wipe_and_reimage | host | Rebuild {target} from a clean image | min_severity=High
5. [recover] patch_and_redeploy | host | Patch the upload vulnerability and redeploy {target} behind WAF rules
