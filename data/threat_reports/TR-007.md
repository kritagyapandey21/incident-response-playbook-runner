# TR-007: Command-and-Control Beaconing from Compromised Endpoints

**Base severity:** 3 (High)
**IOCs:** 193.42.33.14, cdn-update-check.example

## Summary
Compromised workstations running a commercial post-exploitation C2 framework beacon to
attacker infrastructure over HTTPS at a fixed interval with jitter. JA3 TLS fingerprints
match public C2 profiles. Beaconing typically precedes lateral movement and credential
dumping.

## Behaviours
Periodic beaconing, regular interval with jitter, rare external destination, JA3
fingerprint match, command and control, C2 channel, implant on workstation.

## Recommended Containment
1. [preserve] snapshot_host | host | Capture memory image of {target} to extract implant configuration
2. [contain] isolate_host | host | Isolate {target} with EDR
3. [contain] block_ip | ip | Block C2 address {target} at the perimeter
4. [contain] block_domain | domain | Sinkhole C2 domain {target}
5. [eradicate] wipe_and_reimage | host | Reimage {target} | min_severity=High
