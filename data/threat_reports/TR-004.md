# TR-004: Leaked Cloud Access Keys Abused for Cryptomining

**Base severity:** 3 (High)
**IOCs:** 185.220.101.47, p4d.24xlarge

## Summary
Cloud access keys accidentally committed to public GitHub repositories are harvested by
automated scanners within minutes. Attackers call RunInstances from Tor exit nodes to
launch large GPU instance fleets in regions the victim never uses, mining cryptocurrency
and generating very large bills. Keys are often also used for data discovery.

## Behaviours
Access key used from unusual IP, RunInstances in unused region, GPU instances launched,
CloudTrail anomaly, leaked key on public repository, cryptomining, cloud account abuse.

## Recommended Containment
1. [preserve] snapshot_cloudtrail | cloud_account | Export CloudTrail logs for account {target} for investigation
2. [contain] disable_access_key | cloud_key | Deactivate access key {target}
3. [contain] block_ip | ip | Add {target} to deny list in account network ACLs and WAF
4. [eradicate] terminate_instances | cloud_account | Terminate all attacker-launched instances in account {target} | min_severity=High
5. [recover] rotate_credentials | user | Rotate all credentials belonging to identity {target}
