# TR-009: Adware and Potentially Unwanted Programs

**Base severity:** 1 (Low)
**IOCs:** BrowserBoost, bboost.exe

## Summary
Browser toolbars and "boost" utilities bundled with free software inject advertising into
browser sessions. They are a nuisance rather than a targeted threat, but should be removed.

## Behaviours
Adware, potentially unwanted program, PUP, browser toolbar, ad injection, bundled software.

## Recommended Containment
1. [contain] quarantine_file | file | Quarantine {target}
2. [eradicate] run_av_scan | host | Run full antivirus scan on {target}
3. [eradicate] wipe_and_reimage | host | Reimage {target} if the PUP persists | min_severity=High
